## 1. 🌐 Web 与前端操作范例

- [ ] **1.1 自定义域名与 DNS 解析**
  - [ ] 在域名服务商处添加 DNS 记录（CNAME / A 记录）
  - [ ] 在托管平台控制台验证 SSL/TLS 证书生效
- [ ] **1.2 第三方登录与 OAuth 授权**
  - [ ] 在第三方开放平台（如 Google、GitHub、微信等）创建应用并获取 Client ID / Secret
  - [ ] 将生产回调重定向 URL 加入白名单

## 2. ⚙️ 后端与云基础设施范例

- [ ] **2.1 生产数据库迁移执行**
  - [ ] 复核待执行的增量 SQL 脚本
  - [ ] 生产环境运行迁移命令：`<你的数据库迁移命令>`
- [ ] **2.2 生产环境变量注入**
  - [ ] 在云服务商控制台配置生产环境所需的敏感密钥
- [ ] **2.3 Webhook 回调通知接入**
  - [ ] 在外部平台后台配置服务端 Webhook 回调地址
  - [ ] 将 Webhook 签名验证密钥保存至服务端环境变量

## 3. 📱 移动端 App 操作范例 (iOS / Android)

- [ ] **3.1 开发者账号与证书管理**
  - [ ] 在开发者后台配置 App ID、描述文件与发布签名证书
  - [ ] 配置推送通知服务凭证（APNs / FCM）
- [ ] **3.2 应用内购与商店元数据**
  - [ ] 在 App Store Connect / Google Play Console 录入商品 ID 与定价阶梯
  - [ ] 提交应用审核时提供专用测试账号
- [ ] **3.3 物理真机测试**
  - [ ] 在物理真机上验证系统硬件权限授权弹窗（相机、麦克风、地理位置等）
  - [ ] 测试断网离线与网络重新连接后的状态恢复
