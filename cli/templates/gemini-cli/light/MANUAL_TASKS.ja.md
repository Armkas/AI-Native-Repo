# 📋 手動タスク・チェックリスト (MANUAL_TASKS.md)

> [!NOTE]
> 本ドキュメントは、**人間のエンジニアによる外部ダッシュボード操作や実機検証が必要な事項**を記録します。
> AI エージェントは外部コンソールや物理デバイスに直接アクセスできません。手動作業が必要な場合は、ここに `[ ]` チェックボックス形式で追記し、ユーザーに通知してください。

---

## 1. 🌐 Web & フロントエンド

- [ ] **1.1 カスタムドメインと DNS 設定**
  - [ ] ドメインレジストラで DNS レコード（CNAME / A レコード）を設定する
  - [ ] ホスティング環境で SSL/TLS 証明書の発行を確認する
- [ ] **1.2 サードパーティ認証・OAuth 設定**
  - [ ] 開発者ポータル（Google, GitHub 等）で OAuth クライアントを作成する
  - [ ] 本番のリダイレクト URI を許可リストに追加する

---

## 2. ⚙️ バックエンド & クラウドインフラ

- [ ] **2.1 本番データベースのマイグレーション実行**
  - [ ] 適用予定の増分マイグレーションスクリプトを確認する
  - [ ] 本番移行コマンドを実行する: `<マイグレーションコマンド>`
- [ ] **2.2 本番環境変数の登録**
  - [ ] クラウド管理画面に必要な本番シークレットを登録する
- [ ] **2.3 Webhook エンドポイントの設定**
  - [ ] 連携先コンソールでコールバック URL を設定する
  - [ ] Webhook 署名シークレットをサーバー環境変数に保存する

---

## 3. 📱 モバイルアプリ (iOS / Android)

- [ ] **3.1 開発者アカウントと証明書**
  - [ ] App ID、プロビジョニングプロファイル、署名証明書を設定する
  - [ ] プッシュ通知用サービスキー（APNs / FCM）を設定する
- [ ] **3.2 アプリ内課金とストア設定**
  - [ ] App Store Connect / Play Console でアイテム ID と価格階層を登録する
  - [ ] アプリ審査用のデモアカウント情報を準備する
- [ ] **3.3 実機検証**
  - [ ] 物理実機でのパーミッション許諾動作（カメラ、マイク、位置情報等）を確認する
  - [ ] オフライン状態からの再接続時の挙動を検証する
