# 📋 人間 / エージェント境界 (MANUAL_TASKS.md)

> [!NOTE]
> 人間と AI エージェントの間の権限契約です。「コードの編集とチェックの実行」を超える操作の前に、エージェントは必ずこのファイルを読みます。沈黙は承認ではありません。
> ここのルールは**助言的**です。物理的に不可能でなければならない事柄は、ガードレール（ランタイム権限、フック、CI、ブランチ保護）にも必ず入れてください。

---

## 1. [Autonomous] 自律実行 —— 確認なしで実行してよい

- このリポジトリ内のアプリケーションコード、テスト、ドキュメントの読み取りと編集
- `AGENTS.md` に記載された検証コマンド（型チェック、ビルド、lint、テスト）の実行
- 自分が変更したコードに合わせて `docs/` と `.agents/` を同期する
- 現在のタスク用のローカルブランチとローカルコミットの作成

## 2. [Approval Required] 承認が必要 —— 提案して影響を説明し、明確な「はい」を待つ

- 依存関係の追加・削除・アップグレード
- データベーススキーマの変更（承認後もローカル / 開発用データベースにのみ適用）
- 公開 API・RPC 契約・データ形式に対する破壊的変更
- CI、フック、ガードレール、権限設定、またはこのファイルの変更
- `git push`、プルリクエストの作成・マージ
- このタスクでエージェント自身が作成していないファイル・データ・ブランチの削除

## 3. [Manual Only] 人間のみ —— 人間が実施し、エージェントは正確な手順を用意して止まる

- 本番環境のシークレット、認証情報、環境変数
- 本番デプロイ、本番データベースマイグレーション、DNS と証明書
- サードパーティのコンソール：アプリストア、OAuth プロバイダー、決済、プッシュ通知キー、Webhook
- 実機・ハードウェアでのテスト（カメラ、マイク、位置情報、オフライン / 再接続）
- ガードレールや失敗している必須チェックの回避

> エージェントが [Manual Only] の手順に到達したら、下の **保留中** にチェックボックスを追加し、*なぜ*人間の担当なのかを書き、ユーザーに伝えます。境界を回避することは決してしません。
