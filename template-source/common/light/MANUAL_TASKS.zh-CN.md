# 📋 人机边界 (MANUAL_TASKS.md)

> [!NOTE]
> 人类与 AI Agent 之间的权限契约。凡是超出"编辑代码 + 运行检查"范围的操作，Agent 都必须先读本文件。沉默不等于批准。
> 这里的规则是**建议性**的：凡是必须在物理上不可能发生的事，还应同时放进护栏（运行时权限、Hook、CI、分支保护）。

---

## 1. [Autonomous] 自主执行 —— Agent 无需询问即可执行

- 读取并编辑本仓库内的应用源码、测试与文档
- 运行 `AGENTS.md` 中声明的验证命令（类型检查、构建、lint、测试）
- 让 `docs/` 与 `.agents/` 与自己修改的代码保持同步
- 为当前任务创建本地分支与本地提交

## 2. [Approval Required] 需要批准 —— 先提出方案并说明影响，等到明确的"可以"再执行

- 新增、移除或升级依赖
- 数据库结构变更（获批后也只应用到本地 / 开发数据库）
- 对公开 API、RPC 契约或数据格式的破坏性修改
- 修改 CI、Hook、护栏、权限配置或本文件
- `git push`、创建或合并 Pull Request
- 删除并非本次任务中由 Agent 自己创建的文件、数据或分支

## 3. [Manual Only] 仅限人工 —— 由人类执行；Agent 只准备精确的操作说明，然后停下

- 生产环境密钥、凭证与环境变量
- 生产部署、生产数据库迁移、DNS 与证书
- 第三方控制台：应用商店、OAuth 平台、支付、推送证书、Webhook
- 物理真机与硬件测试（相机、麦克风、定位、断网 / 重连）
- 绕过护栏或绕过失败的必需检查

> Agent 遇到 [Manual Only] 步骤时：在下方 **待办** 中添加一个复选框，写明*为什么*必须由人完成，并告知用户。绝不绕过边界。
