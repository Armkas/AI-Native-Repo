## 🚀 त्वरित प्रारंभ: CLI स्कैफोल्ड

अब आपको फ़ाइलों को मैन्युअल रूप से कॉपी करने की आवश्यकता नहीं है। हम आपके पसंदीदा एजेंट रनटाइम और प्रोजेक्ट जटिलता के अनुरूप AI-Native कार्यक्षेत्र को तुरंत बनाने के लिए एक शक्तिशाली CLI प्रदान करते हैं।

**किसी भी खाली डायरेक्टरी में निम्न कमांड चलाएँ:**

```bash
npx ai-native-repo init .
```

### 12-टेम्पलेट मैट्रिक्स
CLI आपसे 12-टेम्पलेट मैट्रिक्स (4 रनटाइम × 3 टियर) में से चुनने के लिए कहेगा:

**चरण 1: अपना एजेंट रनटाइम चुनें**
- `claude-code`: एंथ्रोपिक इकोसिस्टम हुक और कौशल।
- `codex`: ओपनएआई/कोडेक्स एजेंट संरचना।
- `cursor`: कर्सर के `.cursor/rules/*.mdc` ग्लोबल मैचिंग के लिए अनुकूलित।
- `gemini-cli`: गूगल जेमिनी पर्यावरण।

**चरण 2: अपना जटिलता टियर चुनें**
- `light`: सरल स्क्रिप्ट के लिए न्यूनतम संदर्भ फाइलें।
- `standard`: डिफ़ॉल्ट। उत्पादन सेवाओं के लिए पूर्ण संदर्भ, अनुबंध और नियम वास्तुकला।
- `full`: एंटरप्राइज़ ग्रेड। standard के साथ पाथ गार्डरेल (केवल-पढ़ने / केवल-जोड़ने वाली फ़ाइलें, हुक या CI द्वारा लागू) और संदर्भ ताज़गी जाँच।

## ⚠️ सिमैंटिक-अज्ञेयवादी, रनटाइम-जागरूक, मॉडल-ट्यूनेबल (Semantic-Agnostic, Runtime-Aware, Model-Tunable)

2026 तक, उद्योग ने महसूस किया है कि AI-Native रिपॉजिटरी के निर्माण के लिए तीन अलग-अलग परतों को अलग करना आवश्यक है:
1. **मॉडल / मॉडल प्रोवाइडर** (जैसे, OpenAI, Anthropic, Google, DeepSeek, Qwen, Meta, Moonshot, Zhipu, MiniMax): अंतर्निहित मॉडल की क्षमता तय करता है। यहाँ कभी भी किसी विशिष्ट मॉडल वर्शन को हार्डकोड न करें — पूर्ण Runtime × Model Provider मैपिंग के लिए [मॉडल कम्पैटिबिलिटी मैट्रिक्स](spec/model-compatibility.md) देखें।
2. **एजेंट रनटाइम** (जैसे, Claude Code, Codex, Gemini CLI, Cursor)
3. **रिपॉजिटरी मानक**: आपके प्रोजेक्ट का सार्वभौमिक सत्य।

जबकि आपके प्रोजेक्ट के व्यावसायिक शब्दार्थ **मॉडल-अज्ञेयवादी** हैं, उन्हें **रनटाइम-जागरूक** होना चाहिए।

**मॉडल प्रोवाइडर ≠ एजेंट रनटाइम — दोनों को एक ही आयाम में मिलाएं नहीं।** कोई भी रनटाइम किसी एक मॉडल प्रोवाइडर का नहीं होता (Cursor और Claude Code दोनों को Anthropic, OpenAI, या DeepSeek जैसे API-compatible प्रोवाइडर से चलाया जा सकता है)। इसीलिए मॉडल प्रोवाइडर को अलग [मॉडल कम्पैटिबिलिटी मैट्रिक्स](spec/model-compatibility.md) में दर्ज किया जाता है, न कि एक अलग Template के रूप में।
- **Anthropic का Claude Code** `.claude/settings.json` की अपेक्षा करता है।
- **Cursor** `.cursor/rules/*.mdc` की अपेक्षा करता है।

## 🏗 AI-Native वास्तुकला के 8 स्तंभ

1. **संदर्भ ("क्या")**: *`PROJECT_MAP`, `Domains`, `Architecture`*
2. **नियम ("निर्देश और बाधाएं")**: *`AGENTS.md`, `CLAUDE.md`*
3. **अनुबंध ("वे कैसे जुड़ते हैं")**: *`Protocols`, `Schemas`*
4. **कौशल ("विशिष्ट कार्य कैसे करें")**: *`SKILL.md`*
5. **वर्कफ़्लो ("ऑर्केस्ट्रेट कैसे करें")**: *`SOPs`*
6. **उपकरण ("दुनिया को कैसे स्पर्श करें")**: *`MCP Servers`*
7. **सत्यापन ("सबूत")**: *`Tests`, `Validators`*
8. **मानव / एजेंट सीमा ("विश्वास बाधा")**: *`MANUAL_TASKS.md`*
